# Community plugins

Plugins published by people who use orbit. A listing is not a security review: read what a plugin will run before you
install it ([Plugins](index.md)).

| Plugin | Adds |
| --- | --- |
| [forge](https://github.com/JGoterris/orbit-forge) (alpha) | Merge requests and CI of GitHub and GitLab, with `gh` and `glab`: tabs, badges on the services and actions. `orbit plugin install JGoterris/orbit-forge` |

To add yours, publish it in a GitHub repository with the topic `orbit-plugin` and open a pull request to this page
with its name, the `owner/repo` and a line about what it adds. See [Writing a plugin](authoring.md).
